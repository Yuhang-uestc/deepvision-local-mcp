# Vision Perceive v2（多轮识图闭环）

给纯文本主模型用的多轮识图流程。收到图片分析请求时，不要只调用一次视觉工具就回答；按下面的流程把一张图看透，宁多轮、勿幻觉。图片只在本机处理。

## 工具速查

| 工具 | 用途 |
|---|---|
| `image_info` | 先拿尺寸/格式，确定坐标系 |
| `analyze_image` | 本地视觉模型描述画面；`file_paths` 可多图对比（原图 vs 放大图） |
| `ocr_extract` | 系统 OCR 逐字提取文字（含位置） |
| `detect_objects` | YOLO 检测 COCO 80 类（person/car/…），数人/找常见物体 |
| `detect_by_text` | 零样本检测，用文字描述找任意物体 |
| `cv_locate` | 颜色定位（色块）或模板匹配（图标/logo），不依赖模型 |
| `crop_image` | 裁切 + 放大局部区域，小字/小目标必须先用 |
| `draw_bounding_box` | 一次画多个框（boxes 数组），出标注图验证 |
| `list_local_models` | 查看本机 Ollama 模型 |

## 决策树（先选对工具）

1. 先 `image_info` 拿尺寸；描述画面 → `analyze_image`
2. 图里有文字 → `ocr_extract`（小字先 `crop_image` 放大 2–4 倍再 OCR）
3. 数人/常见物体 → `detect_objects`（classes 可过滤，如 `["person"]`）
4. 找任意物体 → `detect_by_text`（text 写具体名词，多个用逗号分隔）
5. 找纯色色块/图例色 → `cv_locate` mode=color（tolerance 调容差）
6. 找小图标/logo → `cv_locate` mode=template（scales 可多尺度搜索）
7. 目标太小看不清 → 先 `crop_image` 放大，再对放大图执行 2–6

## 流程（至少完成 概览 + 聚焦 + 交叉校验 + 综合）

1. **概览**：`image_info` + `analyze_image`（prompt 用"请详细描述这张图片：类型、主体、布局、有哪些文字"）。
2. **聚焦**：根据概览追 1–3 个具体问题（局部细节、人物特征、图表数据、特定区域），每次独立调用 `analyze_image`。
3. **文字提取**：含文字时优先 `ocr_extract`；艺术字/手写/小字先裁切放大再试。
4. **精确定位**：按决策树选 `detect_objects` / `detect_by_text` / `cv_locate`；把坐标一次交给 `draw_bounding_box`（boxes 数组）画完，得到标注图。
5. **局部放大**：小目标/小字区域用 `crop_image` 裁切放大 2–4 倍，对放大图重新 OCR 或分析；必要时 `file_paths` 传原图+放大图给 `analyze_image` 对比。
6. **交叉校验**：用 `analyze_image` 看标注图验证框是否正确（"红框框住的是不是X？偏了往哪移？"）；多轮一致记为核心事实，冲突以多数或更具体者为准。
7. **综合报告**：结构化输出，明确区分"多轮一致确认"与"仅单轮提及"；不确定的如实标注。

## 规则

- 至少完成概览 + 一次聚焦 + 综合，缺一不可。
- 小字、小目标、印章、仪表读数：先放大再识别，禁止直接拿原图硬读。
- 过滤单轮幻觉：某轮声称 prompt 中不存在的输入或与事实矛盾 → 不写入最终报告。
- 定位类回答必须给像素框或归一化坐标并注明依据（检测/颜色/模板），不用模糊的"左上角附近"。
- 输出坐标前先说明图片尺寸（`image_info`），坐标一律像素（x∈[0,W)，y∈[0,H)）。
